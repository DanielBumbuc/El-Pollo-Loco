## 💡Lessons Learned

This project was my first experience with object-oriented programming. I learned how to create, structure, and reuse objects, as well as how different parts of the code interact with each other.

I also gained experience with physics calculations to create realistic game behavior and worked with the HTML Canvas API for the first time to handle rendering, animations, and the game loop.
